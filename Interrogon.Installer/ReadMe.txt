Interrogon
==========

A native Windows app for organizing and reviewing interview prep questions —
Theory Q&A, Work Experience, Code Review, Algorithms, and System Design —
browsable by type, category, and tag, with search and favorites.

Everything runs locally — no cloud calls, no telemetry.


Your data
----------

Questions, categories, and tags live in:
  %LOCALAPPDATA%\Interrogon\

Uninstalling Interrogon leaves this folder alone by default, so your data
survives a reinstall or upgrade.


Bulk importing questions
--------------------------

The app doesn't have a bulk-import UI — for importing many questions at
once from notes or documents, see IMPORT_INSTRUCTIONS.md in the project
repository, which explains the AI-agent-driven import workflow.
